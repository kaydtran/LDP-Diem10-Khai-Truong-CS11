# Điểm 10+ CS11 - Landing Page (v7)

## Deploy lên GitHub Pages
1. Tạo repo mới trên GitHub
2. Upload toàn bộ folder (index.html + img/)
3. Settings → Pages → Source: main → Save

## Tính năng v7
- Header compact: logo + tiêu đề vàng + menu ngang
- Gallery 23 ảnh hoạt động (lightbox)
- CTA "Đăng Ký Ngay" sau mỗi section
- Nút "Đăng Ký Thêm" sau submit
- QR Facebook + Zalo
- Hotline nổi bật trong thank you
- Form hint 10 số điện thoại
